한 화면에 담은 기능

트루나스 웹 UI의 핵심 기능을 카테고리 사이드바로 재정리했습니다.

대시보드

CPU·메모리 사용률, 스토리지 풀 상태, 활성 경보를 한 화면에서 확인. API 버전 차이까지 자동 대응.

스토리지

풀 상태·용량, 데이터셋 추가/삭제, 디스크 목록, 스크럽 수동 실행.

스냅샷·복제

스냅샷 생성·삭제(재귀 지원), 복제 작업 현황 확인.

공유

SMB 추가·삭제, NFS/WebDAV/iSCSI 확인 · 파괴 작업은 항상 확인창 통과.

앱 관리NEW

설치된 앱 목록(버전·상태·컨테이너)과 시작·정지·재배포·업그레이드·삭제.

가상머신NEW

VM 생성(디스크 ZVOL 자동 생성·ISO·NIC·자동시작)과 시작·정지·재시작·전원끄기·삭제.

서비스·작업

서비스 시작/중지 토글, Cron · Rsync · Cloud Sync 작업 확인.

계정·보안

사용자 추가/삭제, 그룹 관리, 인증서 만료일 확인.

플랫폼에 맞는 카드의 순서대로 따라가면 됩니다.

  2. NaDeck.app을 Applications 폴더로 드래그

  2. Windows 경고 시 “추가 정보 → 실행”
  3. SFX에서 아무 폴더나 지정해 압축해제 후 자동 실행됨

연결 방법

API 키만 있으면 30초면 충분합니다. 문제가 생겨도 대비가 되어 있습니다.

  1. 트루나스 웹 UI → Credential → API Keys → Add에서 키 발급 (화면의 Copy 버튼 사용 — 드래그 시 잘릴 수 있음)
  2. NaDeck 연결 설정에 NAS 주소 입력 (기본 포트면 공란, 바꿨다면 주소 또는 포트란에 입력 · 테일스케일이면 매직DNS 또는 100.x.x.x)
  3. API 키 붙여넣기 → 연결 테스트 → 실패하면 진단 실행으로 서버 응답까지 확인 가능

자체 서명 인증서라면 연결 설정의 “TLS 인증서 검증 허용”을 끄세요. 키 문제가 의심되면 진단이 인증 방식 폴백(X-API-Key → Bearer → Basic)까지 자동으로 시도합니다.
